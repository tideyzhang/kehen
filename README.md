# 课痕 · 课堂互动与记录

**上课轻点记分，课后按座位补录，让一个班的课堂记录更顺手。**

课痕是一款面向教师日常教学的离线桌面工具，支持随机点名、座位选人、回答积分、课堂情况、积分汇总和座位编排。上课时使用紧凑小窗，点名后才展开评分卡；课后在管理窗口中批量录入与整理数据。

## 第一次使用

**先完成一次最简单的点名和记分，再按需要增加设置。**

1. **打开设置**：启动后出现点名小窗，点击右侧“⋯ → 设置”。
2. **建立本班并导入名单**：进入“01 班级名单”，填写本班名称，点击“建立本班”；下载名单模板，在 Excel 中填写学号和姓名，保存后“导入并预览”，核对并确认。
3. **点名记分**：返回小窗，点击“随机点名”，确认科目并开始；抽中学生后，点击分值即保存，也可以暂不评分。
4. **完善座位和科目**：进入设置，导入姓名座位表，勾选本班实际科目。之后可以按座位选人和批量录入。
5. **下课后整理**：从“⋯”打开课堂情况、补录回答积分或积分汇总。
6. **保存备份**：进入“设置 → 备份恢复”，导出完整 `.db` 备份。

首次试用可在空数据库的“设置概览”载入 48 人演示班。演示班仅用于熟悉操作，请勿将试录的积分当作正式班级记录。

按步骤操作、Excel 填写示例、结果核对及常见问题见 [完整使用指南](使用说明.md)。课程表和随机排座规则均为可选功能，不影响基础点名。

## 功能介绍

### 课堂互动：小窗点名，按需展开

默认点名小窗为 **184 × 72**，支持拖动与置顶。抽中学生后展开姓名和分值按钮，评分成功后自动收起；等待回答时评分卡会保留。可填写记分备注，也可以暂不评分、继续点下一位或撤销误记。

随机点名与座位选人使用同一课次，切换时保留当前学生和已记录积分。每次随机抽取相互独立，允许重复抽中同一学生。座位图保留实际过道和空位，点击学生才显示评分卡。

### 课后录入：多选学生，分别备注

课堂情况无需先开始课堂。选择日期和科目后，按座位多选学生，登记迟到、缺席等情况；课次可选，也可只记录到当天。情况类型可自行添加与删除。

![按座位多选学生并填写个人备注](docs/assets/screenshots/events-batch-selection.png)

每批可选择“仅记录 · 不计分”、预设分值或自定义分值。每名学生分别填写备注，加入待保存列表后统一核对。分值按每人计算，正数加分、负数扣分。

![核对每名学生的情况、备注与分值](docs/assets/screenshots/events-review.png)

回答积分同样支持课后按座位批量补录、个人备注与自定义分值。删除情况类型不会删除已保存记录；撤销情况时会同步抵消其关联积分。

### 积分汇总：常用范围一键切换

提供 **全部、本月、本周、今天 · 过去24小时、本节课、自选日期** 六种范围，支持科目筛选、座位图与表格展示，以及个人积分明细。

![选择统计范围并查看学生积分](docs/assets/screenshots/points-summary.png)

导出沿用当前筛选范围与表格排序。关联课次的积分按上课开始时间统计，课后补录也归入原课堂。只有日期、没有课次的记录，在过去 24 小时的起始日按整日近似计入，界面会提示。停用或未排座但仍有记录的学生会保留在统计中。

### 座位编排：姓名表格，预览后应用

座位模板直接填写姓名，不要求在座位格中填写学号；可以手动安排，也可以导入 Excel。遇到同名学生时逐项核对，或设置座位专用显示名。

![检查规则、生成座位预览并核对](docs/assets/screenshots/seating-preview.png)

详细排座规则通过 Excel 中的 **座位设置、学生规则、配对避邻** 三张表管理。支持分区、固定位置、配对避邻、横向换组和标记学生两侧前部优先。临时不参与的学生可在“本轮人员”取消勾选，多余位置可留空。

按“检查规则 → 生成座位预览 → 核对 → 应用此座位”操作；预览不会改变正式座位。详细填写方法见 [座位编排说明](docs/座位编排说明.md)。

### 设置：基础准备与可选功能分开

课前准备依次为名单、座位和科目。课程表、随机排座、情况类型、分值与窗口设置按需配置，导入导出和备份另设入口。

![班级设置与按需功能入口](docs/assets/screenshots/settings-overview.png)

名单支持添加、停用、恢复和删除学生。可配置周课程表并开启自动跟课；该功能仅在软件运行期间执行。

## 数据与备份

课痕无需登录账号，核心功能离线运行。数据保存在本机 SQLite 数据库中；安装版使用应用数据目录，Windows 便携版使用程序旁的 `data` 文件夹。

![数据导入、导出与备份入口](docs/assets/screenshots/data-import-export.png)

- **Excel / CSV**：维护名单、座位、排座规则与课程表，交换积分数据，导出汇总、明细和课堂情况。
- **完整 `.db` 备份**：恢复名单、座位、积分、情况及相关设置。**Excel 报表不能替代完整备份。**
- **自动备份**：每日首次启动及导入、删除、恢复等操作前执行；新备份校验成功后按时间保留最近 30 份。
- **换电脑或重新安装**：先导出完整备份；安装版通过备份恢复迁移。便携版须先退出，再复制整个程序文件夹及其中的 `data`。
- **文件命名**：模板、Excel/CSV 导出与手动备份默认包含本机日期和时间，导入不会改写原文件。

具体格式、名单状态规则、数据位置及恢复步骤见 [数据与文件说明](docs/数据与文件说明.md)。

## 开发与验证

使用 Electron、JavaScript、SQLite（sql.js）和 ExcelJS 构建。开发环境为 Node.js 22.22.3、npm 10。

```sh
npm ci
npm start
npm test
```

桌面流程测试包括 `test:ui`、`test:planning-ui`、`test:feedback-ui`、`test:workspace-ui`、`test:roster-ui`、`test:seating-ui`、`test:brand-ui`、`test:reliability-ui`，通过 `npm run 名称` 执行。测试使用隔离目录与虚构学生。

构建命令：`npm run pack:mac`、`npm run build:win`、`npm run build:portable`。源码位于 `src/`，测试位于 `test/`，桌面流程与构建脚本位于 `scripts/`。参与修改请阅读 [贡献指南](CONTRIBUTING.md)，发行流程见 [发布说明](docs/GitHub发布说明.md)。
