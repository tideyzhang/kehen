# 0.7.0 座位规则简化与升级说明

## 这次如何使用

1. 在“设置 → 随机编排与规则 → 规则”下载规则文件。
2. 在 Excel 编辑三张表，保存后导入。检查变更摘要，再点击“确认载入规则草稿”。
3. 如有人仅这次不排座，在“本轮人员”取消勾选；长期不在班的学生仍在班级名单中停用。
4. 根据需要展开“轮换”，选择换组或两侧前部优先。
5. 点击“检查规则”，查看人数、位置和冲突；再生成座位预览。当前座位与预览在同一块网格切换查看。
6. 满意后点击“应用此座位”。不满意可以重新生成；应用前正式座位保持不变。

## Excel 只编辑三张表

| 工作表 | 填写方式 |
| --- | --- |
| 座位设置 | 单个座位网格；上方一行填写轮换组。空白或“通用”表示可用，“留空”表示保持空位；过道沿用当前布局。也可直接填座位分区名称。 |
| 学生规则 | 姓名、座位分区、固定位置、轮换前部优先。固定位置例如“第2排第3列”；不固定留空。 |
| 配对避邻 | 每行两个姓名，不需要学号。 |

最后一张“填写说明”提供操作指引。详细规则仍统一由 Excel 管理，程序不再显示两套座位范围/空位编辑网格。

讲台在下方，第1排靠讲台，列从左向右数。带分区标签的座位只接收同名分区学生，通用座位接收任何分区；因此学生填写分区不表示只能坐该分区。轮换组通常对应一张双人桌的两列，与座位分区是两件事。

如果分区本身就叫“通用”“留空”“过道”，或以“分区：”开头，座位格中应加前缀“分区：”；学生规则中的分区保持原名。例如分区名为“留空”，座位格填“分区：留空”。重新导出会自动处理。

- 删除学生规则的一行：沿用该生现有规则；新生使用默认规则。
- 保留学生行，清空分区/固定位置/优先：清除该项规则。
- 清空配对表的数据行：确认导入后清空配对。
- 删除整张配对表：保留原配对，并在导入摘要中提醒。
- 过道、行列数在“班级座位”调整；规则文件不可直接改变网格结构。

## 姓名、同名及名单同步

座位 Excel、CSV 和座位规则新模板使用姓名，不要求学号。学号和内部学生编号仍在数据库中保留，历史积分不重新分配。

有同名时，导入会按具体单元格要求核对对应学生；核对窗口提供学号帮助辨认。也可在“本轮人员”设置专用于座位的显示名，例如“张晨（甲）”“张晨（乙）”。显示名不会修改班级名单中的正式姓名。导出同名文件时会先提醒。

当前座位导入提供两种方式：

- **仅更新座位**：表外学生继续保持原名单状态。没有新增或恢复人员时默认使用这一项。
- **同步名单**：新增姓名自动顺延学号；恢复匹配的停用学生；表外学生停用。停用前需核对并勾选确认。

有新增或恢复学生时必须通过名单同步确认。导入“上次座位”与规则文件都不会新增或停用名单；规则文件出现未知姓名会指出位置，要求先维护名单。

## 不在班、空位和规则检查

- 名单停用/已删除学生不参与编排，其已有规则及配对保留但暂停作用。
- “本轮不参与”只保留在当前程序的编排草稿中。切换页面、隐藏管理窗口不丢失；应用或放弃本轮后清空；退出程序不保存。
- 旧规则的“不在班”标记不会自行解除。在“本轮人员”逐项选择：转为名单停用、仅本轮不参与，或恢复按名单状态参与。确认前继续排除，确认前自动备份。
- 新建/重置规则中，所有非过道位置默认可用；允许空位多于学生。旧规则中明确关闭的位置继续保持空位。
- 没有上次位置的新生/返班学生只免除这次换组，并在检查详情中列出；其他学生继续换组。固定、分区及配对仍生效。
- 基本检查包含人数容量、固定位置冲突、座位分区/换组可行匹配、与已固定学生的配对冲突。配对的全部组合继续在生成阶段检查。
- 达到搜索时限会提示“本次搜索达到上限”，不宣称规则一定无解，也不会自动放宽硬规则。修改或重新生成后再检查。

历史座位、导出、重置与放弃本轮收在“更多”里。重置需要确认；仅生成预览不会移动学生。应用后保留最近40个应用前后快照。

## 旧数据是否能用

**0.5.0、0.6.0 的 `classroom.db` 可以继续使用。** 本版不改学生、积分、课次和情况的数据表结构；座位显示名和新版规则保存在已有的设置表中。

已经用旧版本生成的真实格式、虚构内容数据库做自动验证，覆盖打开、保存、完整备份恢复，以及名单/座位/积分/情况保留。首次将已有规则保存为新版格式前自动备份；旧排除标记转换前也自动备份。

旧“学号 姓名”座位文件、旧列表规则、v2/v3 网格规则继续可导入。旧文件导入后显示提醒；旧固定空位与排除含义不会自动改变。以后建议从新版重新导出模板，再继续编辑。旧固定当前座位若暂时没有位置，导出为“当前座位（待确定）”；保留此文字可保留旧标记，该生参与编排前需指定有效位置。

### 更新步骤

1. 在旧版“备份恢复”导出完整 `.db`，退出旧程序。
2. 安装版更新仍沿用原来的应用数据目录。
3. 便携版解压到新目录，把旧程序旁的整个 `data` 文件夹复制到新版旁边；不要用新版空 `data` 覆盖旧数据。
4. 打开新版核对学生人数、积分汇总和座位；有旧“不在班”标记时完成一次核对。
5. 数据需要迁移到另一种安装方式时，通过完整 `.db` 恢复。Excel 报表不是完整备份。

不建议新旧两个版本同时写同一份数据库。新版导出的规则文件应使用新版导入；回退程序时使用升级前完整备份，避免旧程序不认识新的规则工作表或丢失新增设置。
