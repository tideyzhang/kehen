# 0.7.1 换座方式与文件命名说明

日期：2026-10-04。

## 截图里的“轮换”是什么

它是随机编排时的两个可选规则。新版入口改名为“换座方式”，并在界面写明适用对象、分组例子和比较基准。

### 每次换到不同的横向座位组

横向组是一组相邻的整列，通常双人桌的两列为一组。例如8列座位可以在 Excel“座位设置”的“轮换组”一行填 `1、1、2、2、3、3、4、4`：

- 第1、2列为第1组。
- 第3、4列为第2组。
- 第5、6列为第3组。
- 第7、8列为第4组。

开启后，上次在第2组的学生，这次必须去其他组，可以是第1、3或4组；同组内往前或往后移动不算换组。没有按固定顺序依次轮转的要求。

固定位置学生保持固定；没有上次位置的新生或返班学生只免除本次换组。座位分区和配对避邻仍然生效。没有换组需要时取消勾选即可。

### 让标记学生优先坐两侧前半区

只有同时满足以下条件的学生享受这项优先：

1. Excel“学生规则”中的“轮换前部优先”填写“是”。
2. 上次位于中间横向组，而不是最左或最右组。

程序会优先安排到最左或最右组、靠讲台的一半排数。固定位置、座位分区和配对避邻仍须满足，所以这项属于优先照顾，可能无法全部满足。

两项都关闭时，仍会按其他规则随机编排。

### 与哪份座位比较

默认使用当前已保存座位。要与更早的一次座位比较，可以导入那次座位 Excel / CSV 作为基准。反复生成使用同一份比较基准；只有点击“应用此座位”才改变正式座位。

这些设置没有定时自动换座功能。

## 文件名统一包含生成日期和时间

下载模板、导出 Excel / CSV 以及完整数据库备份，保存窗口默认文件名统一为：

`原名称-YYYY-MM-DD_HH-mm-ss.扩展名`

例如：

- `2407-座位模板-2026-10-04_17-09-10.xlsx`
- `2407-排座规则-2026-10-04_17-09-10.xlsx`
- `2407-当前座位-2026-10-04_17-09-10.csv`
- `积分汇总-2026-10-04_17-09-10.xlsx`
- `课堂积分备份-2026-10-04_17-09-10.db`

时间取导出电脑的本地时间，精确到秒。文件名没有冒号，兼容 Windows。保存窗口中仍可自行修改文件名。

导入用于读取已选文件，会保留原文件名和原文件内容，不会重新命名。导出生成的带时间文件可直接重新导入，不需要删除日期时间后缀。学生表、规则表的列格式保持原有兼容性。

## 更新与验证

本次不改变排座算法、数据库结构或规则文件格式，原 `.db` 和规则文件可以继续使用。另修复管理窗口偶发在功能模块尚未加载时显示“启动失败”的初始化顺序问题。

测试覆盖73项数据与算法用例，以及实际 Electron 中的11个模板/导出入口、导入文件名称和内容保留、换座说明、管理窗口启动、座位编排和课堂工作区流程。

更新安装版沿用原数据目录；便携版更新前退出旧程序并备份，将旧程序旁整个 `data` 文件夹复制到新版本旁边。Windows 教室的安装、触屏、缩放和 PPT 全屏置顶仍需现场验收。
