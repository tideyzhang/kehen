## 更名与旧数据

**这次更名不更改数据库结构，也不建立一份空白的「课痕」数据库。**

- 应用内部标识仍为 `local.classroom.points`，软件包名仍为 `classroom-points`。
- 安装版明确沿用原 `classroom-points` 数据目录；Windows 通常是 `%APPDATA%\classroom-points`，Mac 为应用数据目录下的 `classroom-points`。
- 数据文件仍名为 `classroom.db`，名单、座位、积分、课次和课堂情况保留原身份与关联。
- Windows 便携版仍使用程序旁的 `data` 文件夹。
- 旧版导出的完整 `.db` 备份继续可用。新导出的备份使用「课痕备份」及日期时间作为默认文件名。

## 更新方式

1. 在原软件中导出完整 `.db` 备份，退出程序。
2. **安装版**：运行 `课痕 Setup 0.7.2.exe`。保留原安装目录，不手动删除旧程序或数据目录。
3. **便携版**：完整解压 `课痕 0.7.2 Windows便携版.zip`，将旧版 `data` 文件夹完整复制到新版程序旁，再运行 `课痕.exe`。
4. **Mac**：使用新版 `课痕.app` 替换应用，数据目录沿用原位置。
5. 核对原名单、座位、积分与备注，再做一次记分、退出重开及备份恢复检查。

Windows 安装、触屏、图标缓存和旧版升级效果仍需在教室电脑按 [实机验收清单](../Windows实机验收清单.md) 验证。系统可能缓存旧快捷方式图标，安装更新后可先重新打开程序并核对程序文件的图标；不要为刷新图标而删除学生数据。
