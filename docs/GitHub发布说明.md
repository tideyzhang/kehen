# GitHub 发布与维护

仓库：[tideyzhang/kehen](https://github.com/tideyzhang/kehen)。公开源码采用 MIT；当前首次测试版为 `v0.7.4-beta.1`。

源码、测试、构建脚本、文档及正式图片进入 Git；安装包、实际数据库、备份和构建中间文件不进入源码历史。Releases 提供 Windows x64 安装版、便携 ZIP、Mac arm64 ZIP 及 SHA256SUMS.txt。

## 发布步骤

1. 在 main 上完成集中修改，更新 package.json 和锁定文件中的版本，运行单元与受影响的桌面流程测试。
2. 在 Windows 构建安装版和便携包，在 Mac 构建 arm64 应用 ZIP；运行 scripts/verify-release.cjs，检查最终附件及第三方声明。
3. 更新 CHANGELOG、数据兼容范围和验证边界，创建与程序版本一致的 v 开头标签。
4. 新建 Release 草稿，上传三份附件及校验文件；下载检查后发布。带 beta 后缀的版本勾选 Pre-release。
5. 已公开的标签及附件不替换内容，修正通过新版本发布。当前不启用自动公开发行。

## 数据兼容与验收

数据库格式和软件版本分别评估。新版发布说明需明确旧 .db 读取、完整备份恢复、数据目录及升级步骤，不以“构建成功”替代 Windows 教室实机安装、触屏、缩放与 PPT 置顶验收。

旧本地历史已完整归档；首次公开仓库不导入旧安装包历史。截图使用虚构演示班。许可原文和清单随每份程序分发，依赖变化时同步更新第三方声明。
