# Windows 使用与排错

## 选择安装版还是便携版

- 安装版通过向导安装，数据保存在当前用户应用数据目录中，适合固定教室电脑。
- 便携版完整解压后运行 `课痕.exe`，数据保存在程序旁 `data`。保留 `portable.flag`、资源文件和 DLL，不能只复制 exe 或在压缩包内运行。
- 两种方式不自动共享数据，切换时导出完整 `.db` 再恢复。软件不能打开时，先完整复制现有数据目录留存，再排查。

下载入口为 [GitHub Releases](https://github.com/tideyzhang/kehen/releases/tag/v0.7.4-beta.1)。安装包尚未签发行者证书；出现系统提示先核对来源，不使用其他站点的同名程序。

## 找不到数据库

安装文件夹和数据文件夹不是同一处。优先在“设置 → 备份恢复 → 打开数据文件夹”查看实际位置。

安装版通常为 `%APPDATA%\classroom-points`，便携版为程序旁 `data`，数据库名为 `classroom.db`。不要为找文件而删除或重建数据目录。

## 小窗被全屏课件盖住

1. 从小窗“⋯”确认已开启置顶。
2. 在“设置 → 按需设置 → 窗口设置”点击“立即重申置顶”。
3. 核对 PowerPoint 编辑态与放映态、投影复制或扩展模式，以及电脑显示缩放。
4. 记录系统、全屏软件、显示比例和复现步骤；使用演示数据按 [实机验收清单](../Windows实机验收清单.md) 检查。

系统锁屏、UAC 安全桌面不属于置顶范围。构建成功或自动测试通过，不等于所有教室软件的全屏置顶均已确认。

## 安装更新提示找不到卸载程序

先备份实际数据目录并记录提示中的路径，检查原安装目录是否被移动、改名或不完整；不要直接删除数据库，也不要清理上层卸载注册表。需要处理残留安装信息时，交由熟悉 Windows 的维护人员核对具体应用项后操作。

## 启动、保存或导入报错

- 记录完整错误、发生阶段、软件版本及安装方式，确认目标位置可写、磁盘空间充足，保留原数据库和备份。
- 遇到 `EPERM`、`fsync` 或替换文件失败，不要把临时库直接覆盖正式库，也不要通过忽略错误来继续录入。
- 数据完整性或关联检查报错时，保留原文件供核对，不自动删除记录或反复新建空库。
- 使用 [GitHub Issues](https://github.com/tideyzhang/kehen/issues) 反馈脱敏信息；涉及安全漏洞使用仓库 Security 页私密报告。

## 日常确认

第一次正式使用前，用虚构学生完成导入、记分、撤销、退出重开、导出、备份恢复和实际全屏操作。触屏、125% / 150% 缩放及教室投影仍需按实机清单逐项检查。
