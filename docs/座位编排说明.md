# 座位编排说明

课痕支持手动座位、姓名 Excel 导入和按规则随机编排。基础操作见 [完整使用指南](../使用说明.md#3-完善座位与本班科目)；以下说明详细规则。

## 基本流程

1. 在“设置 → 班级座位”保存本班名单对应的座位网格与过道。
2. 进入“随机编排与规则”，在“规则”下载 Excel。
3. 编辑座位设置、学生规则、配对避邻三张表，保存后导入，核对并确认载入规则草稿。
4. 在“本轮人员”确认参与者；如需保留规则草稿，点击“保存规则”。
5. 按需要配置“换座方式”，检查规则，再生成预览。
6. 核对当前 / 预览座位，满意后点击“应用此座位”。应用前不改变正式座位。

课堂进行时先结束课堂，再生成或应用。临时不参与人员在应用或放弃本轮后恢复；退出程序不保留本轮排除草稿。

## Excel 怎么填

| 工作表 | 填写内容 |
| --- | --- |
| 座位设置 | 保持现有网格；上方一行填写横向轮换组。座位格空白或“通用”表示可用，“留空”表示保持空位，也可填写分区名；过道沿用当前布局 |
| 学生规则 | 姓名、座位分区、固定位置、轮换前部优先；固定位置例如“第2排第3列”，不固定留空 |
| 配对避邻 | 每行两个学生姓名，表示避免相邻 |

另附“填写说明”工作表。规则文件不用于改变行列数或过道结构，这些内容在“班级座位”修改。

讲台在下方，第 1 排靠讲台，列从左向右数。分区名只限制带标签的座位：写“前区”的位置只能接收“前区”学生，通用位置可接收任何分区。因此，给学生填“前区”不表示他只能坐带“前区”标签的位置。

分区名称恰为“通用”“留空”“过道”，或以“分区：”开头时，座位格需加“分区：”前缀；学生规则中的分区保持原名。例如分区名“留空”，座位格写“分区：留空”。

### 修改和删除规则的含义

- 从学生规则表删除一名学生的整行：沿用该生现有规则，新生使用默认规则。
- 保留学生行并清空某一字段：清除该项分区、固定或优先规则。
- 配对表保留表头、清空全部数据行：确认导入后清空配对。
- 删除整个配对工作表：保留当前配对，导入摘要会提示。
- 规则文件中的姓名必须先存在于名单；未知姓名会提示所在位置，不会自动新增学生。

## 同名学生怎样处理

座位和规则文件使用姓名，不要求学号；内部学生身份和积分关联仍保留。有同名时，导入窗口会按单元格要求选择对应人员，并显示学号辅助辨认。

也可在“本轮人员”设置座位专用显示名，如“张晨（甲）”“张晨（乙）”；该名称用于座位和规则文件，不改变名单正式姓名及历史积分。

## 座位导入与名单同步

- **仅更新座位**：只改变布局，表外学生继续保持原状态；适合名单没有变化、只是调整座位。
- **同步名单**：新增姓名顺延学号，明确匹配的停用或已删除学生恢复原身份，表外学生停用；须核对名单并确认。

新增或恢复人员必须通过同步确认。导入比较基准座位和规则文件均不新增、停用或恢复名单。不要将“没有排到座位”等同于“不在班”。

## 换座方式

### 每次换到不同的横向座位组

横向组是一组相邻整列，通常双人桌两列为一组。在 8 列网格的“轮换组”行填 `1、1、2、2、3、3、4、4`，表示第 1、2 列为第 1 组，以此类推。

勾选后，上次在第 2 组的非固定学生，本次必须去第 1、3 或 4 组；同组内前后移动不算换组，也不要求按固定顺序轮转。固定学生保持固定；没有上次位置的学生仅本轮免除换组，其他规则照常生效。

### 让标记学生优先坐两侧前半区

同时满足两项条件才享受优先：学生规则中“轮换前部优先”填“是”，且上次位于中间横向组。

程序尝试将其安排到最左或最右组、靠讲台的一半排数。固定、分区、配对仍须满足，因此属于偏好，可能无法全部满足。

### 比较基准

默认使用当前已保存座位；需要时，可导入另一份座位 Excel / CSV 作为基准。反复生成使用同一基准，应用后才改变正式座位。两个选项都关闭时，按其余规则随机编排。程序不会定时自动换座。

## 空位、不参与与冲突

- 可用座位多于学生是允许的；明确写“留空”的位置不用于安排。
- 名单停用或已删除学生不参与，其规则和配对保留但暂停作用。
- 临时缺席一次编排，在“本轮人员”取消勾选，不需要改长期名单状态。
- 如果界面提示需要核对既有的“不在班”规则标记，请按人员选择名单停用、仅本轮不参与或恢复参与；确认前继续排除，变更前自动备份。
- 检查包括人数、固定位置、分区与换组的基本可行性，生成时继续检查配对组合。
- 达到搜索上限不代表规则一定无解，也不会自动放宽硬规则。优先检查容量、固定冲突、分区及配对，再重试。

“更多”包含导出已采用座位、历史座位、重置规则和放弃本轮。重置需确认；软件保留最近 40 个应用前后座位快照。
