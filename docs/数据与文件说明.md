# 数据与文件说明

本文说明课痕当前的数据格式和保存规则。逐步操作见 [完整使用指南](../使用说明.md#11-导入备份恢复与换电脑)。

## 文件各自用来做什么

| 文件 | 内容与作用 |
| --- | --- |
| 名单 `.xlsx` | 学号、姓名、可选状态；维护名单，不覆盖积分 |
| 座位 `.xlsx` / `.csv` | 按姓名维护网格、过道与空位；可选择是否同步名单 |
| 排座规则 `.xlsx` | 座位设置、学生规则、配对避邻三张编辑表，另附填写说明 |
| 课程表 `.xlsx` | 课节、时间与周科目；导入预览后保存 |
| 外部积分 `.xlsx` | 每行一笔增减流水，不覆盖总分 |
| 汇总 / 明细 / 情况 `.xlsx` | 按当前筛选范围导出的报表 |
| 完整 `.db` | 恢复名单、座位、课次、积分、情况与相关设置 |

使用软件生成的模板，保留表头与填写说明；不支持用 `.xls` 直接替代 `.xlsx`。包含公式、未知姓名或结构错误时，按预览提示修正后重试。

## 名单导入规则

建立本班后，模板必需字段为学号、姓名，学号建议设为文本。可选“状态”列：

| 输入 | 处理 |
| --- | --- |
| 明确填写“在班”或“停用” | 按填写值更新 |
| 没有状态列或状态为空 | 新学生在班，已有学生保持原状态 |
| 其他非空状态 | 提示所在行，整批拒绝 |
| 文件未出现的学生 | 保持原状态 |
| 学号匹配已删除学生 | 拒绝隐式恢复，提示核对 |

导入预览显示新增、恢复、停用和保持不变的结果；提交前再次校验，整批成功或回退。停用同步移除当前座位，历史积分、情况和规则保留。课堂进行中不能改变已有学生的在班状态。

可识别含“班级”列的名单和外部积分文件，但名称必须与本班一致；不要通过导入其他班级绕过单班工作流。

## 座位文件与名单的关系

座位格使用姓名，空白表示空位，“过道”表示过道。学号与姓名组合也可识别，但不要求使用；同名必须核对实际学生。

仅更新座位不改变名单状态。选择同步名单时，新姓名顺延学号，明确匹配的停用或已删除人员恢复原身份，表外学生停用；确认前应逐项核对。规则导入和比较基准座位导入不执行名单同步。

## 外部积分格式与统计时间

字段为 `学号、姓名、日期、分值、类别、科目、备注`，日期使用 `YYYY-MM-DD`，科目与备注可留空。每行增加一笔流水；文件和内容疑似重复时必须核实，错误批次不部分写入。

关联课次的积分按上课开始时间进入统计；无课次、只有日期的记录按日期统计，“过去24小时”的起始日按整日近似，界面会提示。导出范围与界面一致。

## 文件名与导入原文件

模板、Excel/CSV 导出和手动备份默认命名为：

`原名称-YYYY-MM-DD_HH-mm-ss.扩展名`

例如 `演示班-排座规则-2026-10-23_16-30-00.xlsx`。时间取导出电脑本地时间，精确到秒；保存时可手动改名。导入不修改原文件名与内容，带日期时间后缀的文件可直接重新导入。

## 数据位置

软件无需账号，核心记录存放在本机 SQLite 数据库 `classroom.db` 中。

- **安装版**：当前系统用户应用数据目录下 `classroom-points`；Windows 通常为 `%APPDATA%\classroom-points`，Mac 通常为 `~/Library/Application Support/classroom-points`。
- **Windows 便携版**：`课痕.exe` 旁的 `data` 文件夹，通过 `portable.flag` 识别便携模式。
- **准确位置**：在“设置 → 备份恢复 → 打开数据文件夹”查看，不通过安装目录猜测。

内部名称 `classroom-points` 是数据存储路径，不需要改成中文。安装版与便携版各自保存数据，不会自动同步。

## 保存与备份保护

程序使用临时文件写入、刷盘及替换正式文件的方式保存。数据库保存、事务快照、备份、回滚和恢复后保持关联约束；打开时检查完整性与关联记录，异常时保留原文件并报错，不自动修补或删除记录。

每日首次启动、导入前、删除前、恢复前等操作自动备份。新备份写入并校验成功后，按时间保留最近 30 份；时间戳无法识别时使用文件修改时间。同毫秒备份不互相覆盖，失败不清理原有备份。

手动完整备份可另存到 U 盘等独立位置。**Excel 报表不能替代完整备份，自动备份也不能防止整台电脑或磁盘丢失。**

## 恢复与迁移

1. 在来源程序导出完整 `.db`，保存待录内容并退出。
2. 安装版在目标程序“备份恢复”中选择该文件；恢复前先结束课堂，恢复会替换当前整份数据并自动备份当前数据。
3. 便携版可在退出后复制整个程序文件夹；重新解压程序时，将已有 `data` 完整复制到目标程序旁，不用空目录覆盖。
4. 打开后核对人数、学号、座位、几名学生的积分与情况，再验证记分及重开。

数据复用依据文件结构和完整性判断，而非名称。兼容样本的验证范围见 [测试记录](../测试记录.md)；不要同时用两个程序写同一数据库。数据库异常时先保留原文件及备份，反馈时不公开真实学生信息。
