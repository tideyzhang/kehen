# 课堂积分 · 版本功能与兼容记录

以下保留 0.5.0—0.7.1 的功能演进与兼容说明。项目介绍见 [README](../README.md)，完整操作见 [使用说明](../使用说明.md)。

## 0.7.1 换座说明与文件命名

“轮换”改名为“换座方式”，直接说明横向换组、标记学生两侧前半区优先、固定学生豁免及比较基准。下载模板、Excel/CSV 导出和 `.db` 备份默认文件名包含日期与时间（精确到秒）；导入保留原文件名。

详见 [换座方式与文件命名说明](0.7.1-换座方式与文件命名说明.md)。

## 0.7.0 姓名座位与简化规则

- 座位 Excel/CSV 和规则新模板只需姓名；重名导入逐项核对，可设置专用座位显示名。学号及历史积分保留。
- 详细规则继续由 Excel 管理：座位设置、学生规则、配对避邻三张编辑表；固定位置只填一次，轮换组放在座位网格上方。
- 随机编排页面仅一块主网格，人员、规则、轮换、历史按需展开。先检查、再生成、最后应用。
- 停用学生及相关规则暂时休眠；临时不排座使用“本轮人员”。多余座位允许空着；新生缺少上次位置只免除本轮换组。
- 当前座位导入可选“仅更新座位”或“同步名单”，前者不改变名单状态。
- 旧数据库、旧姓名/学号座位文件和旧规则仍可使用；旧规则转换前备份，不自动打开旧固定空位或解除旧排除标记。

完整操作及更新步骤见 [0.7.0 座位规则简化与升级说明](0.7.0-座位规则简化与升级说明.md)。

## 0.6.0 单班界面与数据兼容

- 只有一个班级时，课堂和课后页面固定显示本班，不再反复要求选择班级；设置中的名单可搜索、筛选状态并导出。
- 本班名单与外部积分新模板可不填“班级”列；仍可导入含正确班级名称的旧模板。导入前显示逐行预览和错误。当前名单快照包含状态与导出时间。
- 座位表导入会列出新增、恢复及停用人数；有学生将被停用时，须展开名单核对并勾选确认。
- “今天 · 过去24小时”按关联课次的上课开始时间统计；未关联课次的旧补录只有日期，起始日按整日近似计入。汇总界面和 Excel 导出采用相同范围。
- 导出名单、积分、课堂情况或完整备份前，先核对班级、范围、条数及文件类型；完整 `.db` 才能恢复全部数据。
- 0.5.0 `classroom.db` 可由 0.6.0 直接打开；自动化测试以旧版生成的真实数据库文件验证了名单、座位、课次、积分、情况和恢复。安装版沿用原数据目录；便携版更新时复制旧 `data` 文件夹。升级前仍建议导出完整 `.db` 备份。

## 0.5.0 名单与批量计分

- 设置 → 班级名单：添加个别学生（学号可自动顺延）、删除学生、删除班级。删除学生保留历史记录；删除整个班级会删除本班关联数据，操作前自动备份并要求确认。
- 导入当前座位表：预览新增、恢复和停用学生，确认后一起保存名单与座位。仅修改座位格或导入“上次座位”不会同步停用名单。
- 补录回答积分：按座位多选、设置每人分值、分别填写备注，核对后整批保存。
- 回答补录及课堂情况均有“自定义分值”，支持正负数及两位小数。课堂情况默认不计分，可选择同时加减分；撤销情况时同步撤销关联积分。
